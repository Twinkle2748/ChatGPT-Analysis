# ChatGPT Analysis

## Project Overview
This project explores how ChatGPT can be used to support data analysis
work. It covers using ChatGPT to understand a dataset, clean data,
generate formulas and queries, and draw insights for decision-making.

## Objectives
- Use ChatGPT prompts to understand and explore a dataset
- Get help with data cleaning and analysis steps
- Generate insights and summaries from the data
- Evaluate how accurate and useful ChatGPT's responses are

## Tools Used
- ChatGPT
- Microsoft Excel (अगर इस्तेमाल किया हो)

## Approach
1. Defined the analysis questions
2. Wrote prompts for ChatGPT
3. Reviewed and verified the responses
4. Documented the results
